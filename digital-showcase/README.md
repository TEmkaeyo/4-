# Цахим бүтээлийн үзэсгэлэн

Дөрвөн цахим контентыг танилцуулах responsive, нэг хуудастай веб сайт.

## Ажиллуулах

`index.html` файлыг веб хөтөч дээр нээнэ. Нэмэлт package болон build шаардлагагүй.

## Файлууд
- `index.html` — вебийн бүтэц ба бүтээлийн картууд
- `style.css` — загвар, анимэйшн, responsive layout
- `script.js` — ангиллын шүүлтүүр, хайлт, дэлгэрэнгүй modal

## Нийтлэх
Энэ хавтсыг Netlify эсвэл Cloudflare Pages руу байршуулж болно. Framework сонголт шаардлагагүй; build command хоосон, publish directory үндсэн хавтас.

## Тэмдэглэл
Картын зураглал нь CSS-ээр хийсэн *символик иллюстрац* юм, эх сайтуудын дэлгэцийн зураг биш. Эх бүтээлүүдийг картын “Бүтээл үзэх” холбоосоор шинэ табд нээнэ. “Этүгэн”-ий тухай баталгаажсан мэдээлэл хязгаарлагдмал тул танилцуулгыг ерөнхий байдлаар бичсэн.

Google Fonts сүлжээгүй үед системийн фонтоор автоматаар солигдоно.
